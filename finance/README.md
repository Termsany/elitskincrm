# المتابعة المالية — Elite Skin

برنامج ويب منفصل لمتابعة المصاريف والمديونيات والأرباح، مربوط بدفترة (قراءة فقط)، مع مساعد ذكاء اصطناعي.
يعمل على `https://finance.eliteskinsa.com` — تدخل عليه من أي مكان (موبايل أو كمبيوتر) بكلمة مرور.

## المميزات
- **الرئيسية**: مبيعات، مشتريات، مصاريف، صافي ربح، وتوقع سيولة.
- **العملاء / الموردين**: المديونيات بالألوان 🔴 متأخر أكثر من شهر، 🟡 أقل من شهر، 🟢 في موعده — مع PDF وكشف حساب.
- **المصاريف**: ثابت متكرر، مؤقت بمدة، ومرة واحدة (تُحفظ داخل البرنامج).
- **البيع والشراء** و**الربح والخسارة** شهريًا من فواتير دفترة.
- **مساعد ذكي** يحلل أرقامك الحقيقية (يحتاج مفتاح Anthropic، وبدونه يعطي تحليل بقواعد ثابتة).
- **مزامنة تلقائية** من دفترة كل ساعة + زر تحديث فوري.

## مكانه وطريقة النشر
البرنامج في مجلد `finance/` داخل ريبو الـ CRM، لكنه **منفصل تمامًا**: container لوحده (مشروع docker اسمه `elite-finance`)، بيانات لوحدها، منفذ 3200، ودومين لوحده.
أي تعديل يتدمج على `main` → GitHub Actions يشغّل `scripts/auto-deploy.sh` على السيرفر → يحدّث الـ CRM ثم يشغّل `scripts/deploy-finance.sh` اللي:
1. أول مرة بس: يعمل ملف الإعدادات `/opt/elite-finance.env` (خارج git) — كلمة المرور فيه = كلمة مرور الأدمن الأولى في الـ CRM (`BOOTSTRAP_ADMIN_PASSWORD`)، وبيانات دفترة منسوخة من إعدادات الـ CRM.
2. يبني ويشغّل البرنامج لو مجلد `finance/` اتغيّر (وإلا يسيبه).
3. أول مرة بس: يضيف موقع Nginx لـ `finance.eliteskinsa.com` (لو `nginx -t` رفضه يشيله فورًا).
4. لما الـ DNS يشاور على السيرفر: يطلّع شهادة HTTPS تلقائيًا.

فشل أي خطوة في البرنامج المالي **لا يوقف ولا يأثر على الـ CRM**. البيانات في Docker volume `elite-finance_financedata` ولا تتأثر بالتحديث.

**الخطوة اليدوية الوحيدة:** في إعدادات DNS للدومين أضف سجل `A` باسم `finance` → `148.230.113.18`.

## تغيير كلمة المرور
```bash
nano /opt/elite-finance.env     # عدّل APP_PASSWORD
cd /opt/elite-crm && FINANCE_ENV_FILE=/opt/elite-finance.env docker compose -p elite-finance -f finance/docker-compose.yml up -d
```

## التشغيل محليًا
```bash
cd finance
npm install
cp .env.example .env   # واكتب APP_PASSWORD
npm start              # http://localhost:3200
npm test               # اختبار كامل مع دفترة وهمية
```

## إضافة مفاتيح دفترة والـ AI
بعد الدخول افتح **الإعدادات**: اكتب الساب دومين ومفتاح دفترة → **اختبار الاتصال** → **حفظ**، والمزامنة تبدأ فورًا.
اكتب مفتاح Anthropic لتفعيل الذكاء الاصطناعي الكامل. المفاتيح تُحفظ على السيرفر فقط ولا تظهر في الواجهة بعد الحفظ.

## أوامر مفيدة على السيرفر
```bash
docker logs -f elite-finance-app-1                                   # اللوج
docker exec elite-finance-app-1 node src/synccli.js                  # مزامنة يدوية
docker cp elite-finance-app-1:/app/data/db.json ./finance-backup-$(date +%F).json   # نسخة احتياطية
```

## الأمان
- دخول بكلمة مرور، مع إيقاف مؤقت بعد 8 محاولات خاطئة لمدة ربع ساعة.
- الكوكي موقّع وآمن (HttpOnly + Secure على HTTPS)، وسر التوقيع يُولَّد عشوائيًا لو مش مضبوط.
- البرنامج يقرأ من دفترة فقط ولا يعدّل فيها.

## معايرة حقول دفترة
لو ظهرت أرقام مديونية غير متوقعة، افتح وأنت داخل البرنامج `/api/daftra/sample` لعرض عينة خام من فاتورة بيع وشراء، واضبط أسماء الحقول في `src/daftra.js`.
